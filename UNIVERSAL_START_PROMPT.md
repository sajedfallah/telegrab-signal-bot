```text

First perform the full repository audit defined in AI_WORKFLOW.md.

Update PROJECT_MASTER.md with the verified current project state.

After the audit, independently provide your own evidence-based recommendations for improving and developing the project, including architecture, code quality, security, testing, performance, reliability, maintainability, deployment, developer experience, user experience, scalability, automation, and useful future features.

- verified facts
- confirmed requirements
- your recommendations

Do not implement recommendations without explicit approval.

At the end provide:
1. Overall project state
2. Rough completion estimate (clearly marked as an estimate)
3. Completed features
4. Partially completed features
5. Missing features
6. Broken or risky areas
7. Top 5 next executable actions
8. Top 5 recommended improvements
9. Quick wins
10. Strategic long-term improvements
11. Optional future feature ideas
12. Whether the project is safe to continue developing in its current state
```
