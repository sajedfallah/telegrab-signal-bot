# Approved UI Decisions

1. Provider Panel is a separate B2B workspace; existing NEXUS customer Mini App is preserved.
2. Desktop uses dark navy sidebar + light dense data workspace.
3. Dashboard must retain charts, KPI cards, tables, quick actions and health indicators.
4. Navigation: Dashboard / Signal Center / Copy Trade / Subscribers / Reports / Branding / Settings.
5. Charts are functional canvas components, not screenshots or decorative placeholders.
6. Responsive layout is required.
7. Branding is tenant-driven; NEXUS hard-coded branding must not be assumed for future providers.
8. Backend integration replaces fixture values without simplifying/removing approved UI components.
9. Live trading/business truth must come from tenant-scoped backend/MT5/Telegram/license data, never synthetic production values.
