# گیت اتصال Backend

UI تاییدشده پیاده شده، اما اتصال به Backend تا عبور Tenant Foundation از Validation Production انجام نمی‌شود. ترتیب اتصال: احراز هویت Provider و RBAC → Dashboard/Health فقط خواندنی → Branding → Signal Center → lifecycle تلگرام → Customer → Copy Trade License/Credit → Reports. این ترتیب برای جلوگیری از Cross-Tenant و آسیب به Runtime فعلی NEXUS است.
