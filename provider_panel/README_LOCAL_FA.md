# پیش‌نمایش محلی Provider Panel

از ریشه پروژه در PowerShell اجرا شود:

```powershell
python .\provider_panel\serve.py
```

سپس در مرورگر باز شود:

`http://127.0.0.1:8091`

این نسخه فقط برای بررسی UI است و داده‌های داخل Dashboard نمونه نمایشی هستند. هیچ‌کدام از قیمت‌ها، درآمدها، سیگنال‌ها، وضعیت MT5 یا Copy Trade در این Preview به‌عنوان داده Live/Production در نظر گرفته نمی‌شوند.

پوشه `miniapp/` فعلی NEXUS دست‌نخورده باقی مانده است.
