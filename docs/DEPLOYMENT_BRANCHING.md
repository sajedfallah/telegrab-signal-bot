## Environment map

### Development

Development is local, not a permanent Vercel deployment.

- UI-only: `python -m http.server 8088 --directory miniapp`
- URL: `http://127.0.0.1:8088`
- Branch: any short-lived developer branch created from current `main`.
- Telegram-authenticated API calls do not work in a normal browser without valid Telegram `initData`.

### Preview / staging

Vercel Preview is the staging layer.

- Trigger: push to a non-production GitHub branch and PR updates.
- URL: generated by Vercel.
- Stable branch alias: generated automatically per branch.
- PR visibility: confirmed; `vercel[bot]` posts a Preview link in the PR conversation. Verified on PR #48 where the deployment status is `Ready` and a branch Preview URL is published.
- Root directory: `miniapp`.
- API route: same production VPS API through the rewrite in `miniapp/vercel.json`.

There is no permanent `staging` branch. The PR Preview is the pre-production environment.

### Production

- Trigger: commit/merge to `main`.
- Canonical URL: https://telegrab-signal-bot.vercel.app/
- Frontend release lineage: PR #51 introduced the approved Mini App production frontend into `main`.
- The exact production deployment ID changes whenever `main` changes; the canonical production identity is the stable domain `https://telegrab-signal-bot.vercel.app/`, not an ephemeral deployment ID.
- Telegram BotFather points the Main Mini App to the canonical production URL.
- Telegram default menu button points to the same URL.

## Environment variable audit

The Mini App source contains no `process.env`, `import.meta.env`, `VITE_*` or `NEXT_PUBLIC_*` dependency. The frontend is static and the backend target is declared in `miniapp/vercel.json`.

Expected Vercel application secrets: **none**.

Do not copy VPS secrets to Vercel. Bot token, broker/MT5 credentials, payment secrets and database/runtime configuration remain on the VPS. The connected Vercel tool does not expose secret values; functional validation is based on source configuration and successful production proxy health.

## Rewrite contract

`miniapp/vercel.json` contains:

```text
/miniapp/api/:path* -> https://api.nexustrade.ir/miniapp/api/:path*
```

The VPS remains the authority for Telegram authentication and protected API behavior.

## Deployment rules

1. Never deploy backend/MT5 runtime to Vercel.
2. Never use a raw deployment URL as the BotFather production URL.
3. Use Vercel Preview for review before merging frontend changes.
4. Production is only from `main`.
5. A release branch is temporary and must not become another production source.
6. Rollback should use a known-good Vercel production deployment or revert the `main` merge; do not reset the VPS as part of a frontend rollback.
