# SIGNAL-AGENT — Release C: Context Engine
Deterministic shadow/context-only layer consuming Release B events and Release A closed candles. It creates immutable, versioned multi-timeframe context snapshots with evidence links.

Outputs include D1/H4/H1/M15/M5 structure bias, HTF bias, MTF alignment/conflict, dealing range and premium/discount location, Daily Quadrant relation and priority 50/75 levels, active liquidity/recent sweeps, active FVG/OB/Breaker POIs, timezone-derived session context with observed session open/high/low, and deterministic context state.

It has no Setup Engine, setup score, TRADE/NO-TRADE, Entry/SL/TP, signal generation, Telegram publication, or AI authority. Existing Signal Authority and AUTOTRADE-DATA-ANALYSIS remain isolated.
